# Sensors & Components

This folder is a library of documentation for all the sensors used in the IDEAs Clinic. It may not be comprehensive at this time, as co-ops will only add documentation as they use the components. If you know how to use a component well and would like to add to our documentation, let us know! We can check and add your documentation, and will credit you as appropriate.
