# Activity 1: What is a Physical Computing System?
A physical computing system is using a microcontroller to take in inputs from hardware and control outputs such as lights, displays, motors, and more. They are created by assembling and wiring the hardware components and programming it with the desired behaviour. 

Physical computing systems can be found in many everyday technologies, including smart home devices, fitness trackers, medical devices, and environmental monitoring systems. A commonality between all of those systems, is that they all have the process of Input > Microcontroller > Output. The input takes information from the environment (eg. button press, sensor) and sends it to the microcontroller where the information is processed according to a program and then displayed as an output in a way that makes sense for the system. This flow is important to recognize and think of as helps with planning and integrating the system. It can assist with breaking down complex system into smaller and simpler parts when creating and designing a system.
