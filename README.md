# IDEAs Clinic Tech Resources

If you are looking for guides on all of the technologies used in IDEAs Clinic challenges, you're in the right place!

> [!info]
> This repository is currently a work in progress.

**Table of contents:**

- The [microcontrollers section](./Microcontrollers/README.md) provides a general guide on using the Arduino and STM32 boards.
  These are also called "embedded boards" or "embedded systems."
- The [FPGA section](./fpga/README.md) covers how-to guides and code samples for the FPGA boards owned by the IDEAs Clinic.
- The [machine learning section](./Machine_Learning/README.md) covers the general ML workflow, plus computer vision guides for [OpenCV](./Machine_Learning/Machine_Vision/README.md) and [MediaPipe pose detection](./Machine_Learning/Machine_Vision/Health_Related_Application.md).
- The [Python section](./Python/README.md) covers setting up Python and virtual environments.
- The [3D modeling and printing section](./3D_Modeling_and_Printing/README.md) covers SolidWorks and FDM 3D printing basics.
- The [UI design section](./UI_Design/README.md) covers getting started with Figma.
- The [vibe coding section](./vibe_coding/README.md) covers using GitHub Copilot in a workshop setting.
