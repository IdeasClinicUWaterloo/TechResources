# Activity 1: What is a physical computing system?
A physical computing system is using a microcontroller to take in inputs from hardware and control outputs such as lights, displays, motors, and more. 
They are created by assembling and wiring the hardware components and programming it with the desired behaviour. 

Physical computing systems can be found in many everyday technologies, including smart home devices, fitness trackers, medical devices, and environmental monitoring systems.
A commonality between all of those systems, is that they all have the process of Input > Microcontroller > Output.
